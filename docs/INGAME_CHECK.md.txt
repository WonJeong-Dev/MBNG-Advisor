# 게임 확인 목록 (API 공개용)

앱에는 있지만 근거가 나무위키·커뮤니티라서 API에 싣지 못한 데이터입니다.
게임 화면으로 확인해 주시면 출처를 '게임 화면 직접 확인(ingame)'과 확인일로 바꿔 API에 공개합니다.
앱 화면의 값은 지금도 그대로 쓰고 있고, 확인 결과가 다르면 앱도 함께 고칩니다.

작성: 2026-11-11 · 개수는 앱 데이터(MBNG Advisor.html) 기준

## 보내는 방법

- 해당 화면을 캡처해 대화에 붙여넣어 주세요. 한 화면에 여러 개가 보이면 한 장으로 충분합니다.
- 캡처를 받은 날을 확인일로 적습니다. 캡처에 날짜가 보이지 않아도 됩니다.
- 한 번에 다 하지 않아도 됩니다. 데이터 하나(예: 가공 시설 하나)를 다 확인하면 그 부분부터 공개합니다.
- 앱 값과 다른 칸이 나오면 게임 화면 값을 따르고, 날짜와 함께 기록합니다.

## 게임 화면이 아니라 원문 주소가 필요한 것

| 데이터 | 필요한 것 | 이유 |
|---|---|---|
| 각인 강화 확률 | NEXON NOW 확률 페이지 주소(브라우저 주소창 복사) | NEXON NOW는 자동 접근을 막아 사람이 연 주소를 출처로 적습니다 |
| 기억 각인 규칙 | 공식 가이드·노트에 있는 문장만 쓰도록 정리 중 | 앱 문구에 커뮤니티 근거가 섞여 있어 공식 문장만 따로 추립니다 |
