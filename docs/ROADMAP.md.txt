# 로드맵 (완전성 게이트를 통과해야 착수)

1. ✅ 직업 주·부 스탯 → 직업 정보 표시, 주·부 조합 자동 묶음 (2026-10-27 완료)
2. ✅ 숙련 연계 → 보너스표 조회 + 추가 공격력 계산기 (2026-10-27 완료, 공식 3/26·6/25 업데이트 노트)
   갱신 시: 새 업데이트 노트에 숙련 연계 수치 변경이나 ★11 이상이 나오면 LK/LKH와 LINK_SRC 교체
3. ✅ 가공 레시피 조회 (검색·시설·레벨 필터, 재료 눌러 가공 단계 추적) (2026-10-27 완료, 시간 열 제외)
   후속: 레시피별·시설 레벨별 가공 시간 자료가 나오면 시간 열 추가
4. ✅ 채집 바로찾기 → 아이템 검색·스킬 탭·가공 레시피 연결 (2026-10-27 완료, 지역 열 제외)
   후속: 채집물 지역 자료, 서쪽 호수 낚시터 호미 상자 확인 시 반영
5. ✅ 주간 체크리스트 (월 06:00 KST 자동 초기화, 13항목·카운터·목록 편집) (2026-10-27 완료)
   갱신 시: 레이드가 바뀌거나 주간 횟수가 바뀌면 WEEKLY와 WK_DATE·RAID_DATE 교체
6. ✅ 소울스트림 → 생산·구매 계산기(게임 화면 값 입력), 생산 구간표, 주간 구매 가격표, 부캐 매력 루틴 (2026-10-27 완료, 별·멤버십 제외)
   후속: 생산 별·매력 별 수치를 게임에서 확인하면 별 효과(회수 기간) 계산 추가
7. ✅ 물물교환 → 주괴 교환 경로, 가공 대신 교환(가공 n회분), 캐릭터 수별 최대 획득량, 전체 129건 검색·지역·주기 필터 (2026-10-27 완료)
   + NPC 주간 상점 탭(골드·하트 토큰 138건, 캐릭터 수별 최대 구매량·비용, 두 탭 공용 검색) (2026-10-27 완료)
   후속: 시설 레벨별 가공 시간이 확인되면 '가공 n회분'을 시간으로 환산
8. ✅ 필드 보스 칭호 → 막타 칭호 6종 효과·선행 보스, 21개 직업별 추천·대안·근거, 직업 상세에 추천 칭호 표시 (2026-10-27 완료)
   갱신 시: 새 필드 보스·칭호가 나오거나, 나무위키 전사 문서 '각인 재설정'이 채워지면 FBT·FBT_CLS 교체(전사는 시즌2 자료로 다시 판단)
9. ✅ 에픽 펫 추천 → 판매 중인 에픽 18종 + 승급 펫 1종 기준 21개 직업별 1순위·대안·조건·스탯 목표 근거, 조합별 카드, 주요 펫 고유 스킬, 직업 상세에 추천 에픽 펫 표시 (2026-10-29 펫 추천 → 2026-11-02 에픽 추천으로 교체, 75종 목록·등급표 삭제)
   갱신 시: 새 펫 럭키박스가 나오면 공지의 에픽 구성으로 PET·PET_DATE 교체(능력치는 아카라이브 '펫 옵션' 글, 브라우저로 읽기). 컨닝페이퍼 새 갱신본이 나오면 직업별 스탯 목표로 PET_CLS 재검토
   후속: 18종 전부의 고유 스킬 자료가 나오면 PET 표에 고유 스킬 열 추가
10. ✅ 거래소 → 모비라이프 OpenAPI 시세판(급등·급락·품귀·재입고, 전 품목 검색, 제작 재료 시세), 시세 상세(90일 차트·판단·월드 채팅 언급), 가공 수익, 장비 제작비(잔영·해연 76종), 교환 차익, 관심 품목·목표가, 가공·물물교환 페이지 시세 표시 (2026-11-01 완료, 키는 사용자 브라우저에만 저장)
   갱신 시: 약관·호출 한도가 바뀌면 MK_MAXCALL·MK_TTL 조정. 가공 레시피·물물교환이 바뀌면 자동 반영
   후속: 가공 시간 자료가 나오면 시간당 수익 추가. 해연 '레시피로 제작' 재료를 받으면 제작비 탭에 추가
11. ✅ 룬 경합 → 부위별 마지막 칸 vs 다음 순위 추세 판단(교체 권장·장기 추세·교체 확정·역전 1주차·주시), 직업 상세 경합 현황, 룬 역검색 교체 신호 탭, 룬 순위 사용률 정렬 (2026-11-01 완료)
   갱신 시: 요청 시 대시보드 주간 수치로 RC·RC_W·RC_DATE 교체(scratchpad rc_build.js 방식). 룬 캡처를 새로 받으면 RAW와 DATA_DATE 교체
12. ✅ 빌드별 세공 → 직업 상세·직업 비교를 빌드 단위(쓰임·기준·장신구 룬·개조·세공 순위)로 통합, 복사 문구·검색·카드·표 반영 (2026-11-02 완료)
   갱신 시: 컨닝페이퍼 새 갱신본으로 BLD·BLD_DATE 교체, 값마다 기준일을 먼저 확인
13. ✅ 신규 육성 준비물 → 100레벨까지 스토리 필수 재료 합계·보유 수량·다음 막힘 계산, 퀘스트별 완료 표시 (2026-11-02 완료)
   갱신 시: 사용자 목록을 받아 QST·QST_DATE 교체
