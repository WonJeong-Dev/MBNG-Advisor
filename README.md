# MBNG Advisor

마비노기 모바일 정보·자동 계산 도구 (비공식, 개인용). 이전 이름: ERIN HUB.

- 바로 열기: https://wonjeong-dev.github.io/MBNG-Advisor/
- 앱: `MBNG Advisor.html` 하나로 동작합니다. 외부 라이브러리·통신 없이 오프라인으로 열 수 있습니다.
- `index.html`은 GitHub Pages 주소에서 앱으로 넘겨 주는 연결 파일입니다.
- 데이터 상태와 출처: `docs/DATA_STATUS.md.txt`, 진행 계획: `docs/ROADMAP.md.txt`
- 입력값은 브라우저 localStorage `mbng_advisor_v3`에 저장됩니다(예전 `erin_hub_v3` 값은 처음 열 때 자동으로 옮겨집니다).
